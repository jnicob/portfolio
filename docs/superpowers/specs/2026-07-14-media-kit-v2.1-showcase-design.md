## Contexto y objetivo

La v2 (F2.5) entregó el lightbox con zoom/pan/fit/fullscreen/auto-hide y el slider en modo
hover. Esta iteración lo lleva un paso más hacia calidad de producto, a partir de fricciones
reales de uso, y pule el showcase:

- **MediaLightbox:** pan con `Espacio` + arrastrar (convención Figma) y cursor `grab`;
  caja de ayuda de teclado (`?`); el toggle de controles pasa a icono **ojo / ojo-tachado**
  con tooltip.
- **CompareSlider (demo):** nuevo ejemplo **color/B-N** a pantalla completa con un retrato
  generado por IA.
- **Showcase:** fix del layout-shift de `Tabs`, y enriquecimiento (estructura + intros,
  estados + variantes, pulido visual) en ambos temas.

Es **optimización aditiva**: ninguna capacidad v2 (a11y incluida) se pierde.

## API pública

### CompareSlider

Sin cambios de API. El ejemplo color/B-N usa las props `before`/`after` existentes: `before`
es el `<img>` con `style={{ filter: 'grayscale(1)' }}`, `after` el mismo `<img>` en color.

### MediaLightbox

Comportamiento nuevo sin props nuevas: `Espacio`+arrastrar (pan) y tecla `?` (ayuda). El
único cambio de superficie es ampliar `MediaLightboxLabels` con las claves de la ayuda y del
tooltip del ojo (todas con default en inglés):

```ts
type MediaLightboxLabels = {
  // ...claves v2 sin cambios (incluye hideControls/showControls, reutilizadas por el ojo)...
  /** aria-label del botón de ayuda. Default 'Keyboard shortcuts'. */
  help: string;
  /** Encabezado del panel de ayuda. Default 'Keyboard shortcuts'. */
  helpTitle: string;
  /** Descripciones de cada atajo (para i18n del panel). Default en inglés. */
  shortcutZoom: string; // p.ej. 'Zoom in / out'
  shortcutReset: string; // 'Reset view'
  shortcutPanKeys: string; // 'Pan'
  shortcutPanDrag: string; // 'Hold Space and drag to pan'
  shortcutFit: string; // 'Cycle fit mode'
  shortcutFullscreen: string; // 'Toggle fullscreen'
  shortcutControls: string; // 'Show / hide controls'
  shortcutHelp: string; // 'Toggle this help'
  shortcutClose: string; // 'Close'
};
```

Los tipos públicos siguen exportándose desde el barrel (`MediaLightboxFit`,
`MediaLightboxLabels`). Los hooks siguen internos.

**Modelo de la ayuda:** panel presentacional `LightboxHelp` (interno) que recibe `labels` y
renderiza filas `⟨tecla(s)⟩ — ⟨descripción⟩`. Las teclas (glifos: `+`, `−`, `0`, `←↑→↓`,
`Espacio`, `f`, `c`, `?`, `Esc`, `doble-click`, `rueda`) son literales; las descripciones
salen de `labels`. Región etiquetada `role="group"` + `aria-label={helpTitle}` (NO un `dialog` anidado dentro
del dialog modal), foco gestionado al abrir/cerrar, dismissible con `Escape` (precede al
cierre del lightbox).

**Responsabilidades nuevas:**

- **Espacio-pan** — el estado "espacio pulsado" vive en `media-lightbox` (keydown/keyup sobre
  el dialog). Mientras está pulsado: cursor `grab`, y el arrastre panea (mismo clamping de
  `useZoomPan`). Se hace `preventDefault` del scroll de página SOLO cuando el foco no está en
  un botón (así `Espacio` sigue activando botones). Se libera el estado en `blur`/ocultar para
  no quedar "pegado". Sin cambios en `useZoomPan`.
- **`LightboxHelp`** — presentacional puro; sin lógica de gestos. `media-lightbox` controla su
  visibilidad (estado `helpOpen`) y la precedencia de `Escape`.
- **Ojo/ojo-tachado** — SVG inline en `media-lightbox` (reemplaza el `⋯`); `aria-label` +
  tooltip reutilizan `hideControls`/`showControls`. Tooltip: CSS puro sobre `data-*`/`aria-label`.
- **Tabs** — `TabPanel` renderiza siempre y usa `hidden` cuando inactivo (en vez de `return null`).

**Flujo de datos:** igual que v2 (unidireccional). Sin dependencias runtime nuevas.

## Interacción y accesibilidad

- **Mapa de teclado (dialog):** v2 + `Espacio` (mantener+arrastrar = pan) + `?` (ayuda).
  Precedencia de `Escape`: fullscreen nativo → panel de ayuda → cerrar lightbox.
- **Ayuda:** al abrir, el foco entra al panel; al cerrar, vuelve al disparador. `inert`/trap
  coherentes con el resto del dialog.
- **Tooltip:** visible en `hover` y `focus`; nunca única fuente de información (el `aria-label`
  ya nombra el botón).
- **Ojo:** `aria-pressed`/`aria-expanded` coherente con el estado de la toolbar.
- **WCAG AA en ambos temas** para todo lo nuevo (iconos, tooltip, panel, `:active`). El retrato
  y su B-N son decorativos con `alt` significativo en el "antes" y `alt=""` donde aplique.
- **prefers-reduced-motion:** sin transiciones de transform (heredado de v2).
